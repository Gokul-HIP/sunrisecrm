Content Calendar Special Day Banner Backgrounds
==================================================

Recommended filenames:
1. special_day_bg.jpg (Desktop)
   - Recommended dimensions: 1920 x 300 px (or similar wide landscape aspect ratio ~6.4:1)
   - Layout guidance: Subject/artwork on the right side; darker/clearer background on the left to allow crisp text contrast.

2. special_day_bg_mobile.jpg (Mobile)
   - Recommended dimensions: 780 x 300 px (or 1080 x 400 px)
   - Layout guidance: Optimized for portrait/small viewport viewing.

Fallback:
If no background image is present in this directory, the CRM automatically applies an elegant gradient derived from the CRM orange theme color with full WCAG AA contrast (contrast ratio >= 4.5:1).
